# Code of Conduct

## Our commitment

This project is committed to a welcoming, safe, and constructive community. Everyone participating in the project is expected to treat others with respect, regardless of background, identity, experience, or viewpoint.

## Expected behavior

- Communicate respectfully and assume good intent.
- Give specific, constructive technical feedback.
- Welcome questions and different levels of experience.
- Respect privacy and never share tenant, user, credential, or authentication data.
- Keep discussions focused on improving the project.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Sexualized language or unwanted attention.
- Deliberate intimidation, disruption, or repeated bad-faith argument.
- Publishing another person's private information without explicit permission.
- Sharing sensitive organizational or identity data in project spaces.

## Enforcement

Project maintainers may edit, remove, or reject comments, commits, issues, pull requests, and other contributions that violate these expectations. They may also temporarily or permanently restrict participation when necessary.

Report conduct concerns privately to the maintainer using a private contact method listed on the [maintainer's GitHub profile](https://github.com/fredlahoud). Do not include confidential tenant or authentication data. Reports will be reviewed fairly and kept as confidential as practical.

## Scope

This code applies in all project spaces and whenever someone is publicly representing the project.
